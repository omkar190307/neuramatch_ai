# neuramatch_ai

## Description
NeuraMatch is an AI recommendation engine that utilizes a core algorithm based on weighted cosine similarity to provide personalized recommendations across various media categories, including movies, music, and books.

## Features
- AI-driven recommendations based on user preferences.
- Support for multiple media categories: movies, music, and books.
- Customizable dataset for easy expansion and updates.

## Tech Stack

## Installation
1. Clone Repository: `git clone <repository_url>`
2. Install Dependencies: `pip install -r requirements.txt`
3. Run Project: `python server.py`

## Usage
To use the application, run the server with the command specified in the installation section. Access the application through your web browser at `http://localhost:5000` (or the specified port). Follow the on-screen instructions to interact with the recommendation engine.

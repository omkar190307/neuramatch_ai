How the Engine Works

1
User Vector

Your selected tags and slider weights form a weighted feature vector U = [w1, w2, ..., wn]

2
Item Vectors

Each item has a feature vector I = [0/1, ...] encoding which genres/tags it belongs to.

3
Cosine Similarity

sim(U, I) = (U · I) / (|U| × |I|) — measures angular closeness in feature space.

4
Ranked Output

Items are sorted descending by similarity score and the top matches are presented to you.
